# Alışveriş Listesi

Aile içi ortak alışveriş listesi. Ürünler, nereden ve kaça alındığı kaydedilir.
"Alışverişi bitir" denince toplam tutar ve ödeme şekli (nakit/kart) kaydedilir;
Hesap Defteri uygulaması bu toplamı okuyup ilgili hesaptan gider olarak düşer.

- Veriler: Firebase Firestore, `alisveris` koleksiyonu
- Giriş: Google hesabı (yalnızca izin verilen iki Gmail adresi)
- Yayın: GitHub Pages
